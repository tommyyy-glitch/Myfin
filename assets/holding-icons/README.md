# Investment identification images

Public stock, ETF issuer and cryptocurrency graphics for user-selected holding icons. Exact publisher pages, downloaded URLs, file sizes and SHA-256 hashes are recorded in `sources.json`. These assets identify holdings; they do not imply sponsorship or affiliation. Brand owners retain their trademarks and image rights. Public availability is not a blanket licence to reuse a brand.

Google and Amazon use their official website icons. NVIDIA keeps its complete official vertical mark and original proportions. Vanguard and Invesco identify the fund issuer, so VOO and VT share the Vanguard picture; QQQ uses the Invesco picture. These are not exclusive ETF logos, and the app must retain each holding’s name and symbol beside the image.

Bitcoin uses BitPay’s public-domain (CC0) vector icon. Ethereum uses the official ethereum.org repository’s purple diamond. BNB uses the current official BNB Chain website logomark. The Vanguard and BNB ICO images were decoded into PNG without resizing or changing their artwork. Bitcoin SVG line endings were normalized to LF without changing vector artwork. Other files retain the downloaded bytes.

No account balances, transactions, private screenshots, credentials or user uploads are included. Matching assets must be previewed and applied through the app; a software release must not rewrite stored holding metadata automatically.
